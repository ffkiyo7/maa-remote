# Discord 使用手册

这份文档只讲一件事：**在 Discord 那个频道里，会自动发生什么，以及你能做什么。**
不涉及部署和代码，那些看 [README.md](../README.md) 和 [DEV_GUIDE.md](./DEV_GUIDE.md)。

频道里说话**不用 @ 机器人**，直接说人话就行。

---

## 一、自动发生的事

### 每天固定发生（北京时间）

| 时间 | 做什么 | 频道里会看到 |
|---|---|---|
| 每 15 分钟 | 检查 MAA 里的当期活动 | 平时安静。轮换/异常时才说话（见下） |
| 04:30 | 仓库对表（满 7 天才真跑，未到期不开模拟器） | 只在失败时发 ❌ |
| 07:50 | 跟随 maa-cli / MaaCore 更新 → 刷新活动关 → 发**早场计划卡** → 清掉 24h 前的子区和 14 天前的运行文件 | 🌱 **MAA 今日计划 · 早场 08:00**（可点） |
| 08:00 | 按**早场**的计划跑一遍完整日常 | 🌱 开始 → 子区里滚动步骤 → ✅/❌ 战报 + 主界面截图 |
| 21:50 | 刷新活动关 → 发**晚场计划卡**。**不跟随上游更新**（早上跟过了） | 🌱 **MAA 今日计划 · 晚场 22:00**（可点） |
| 22:00 | 按**晚场**的计划跑，任务链完全一样 | 同上 |

发新计划卡时，旧计划卡的按钮会被**清空**，避免同时存在两张能点的卡——
所以 21:50 之后早场那张就点不动了，这是故意的。

### 一天两张卡，两场分开管

早场卡管 08:00，晚场卡管 22:00。**你在一张卡上改的关卡或跳过，只影响那一场**：
早上选了 `CE-6`，晚上仍然走系统按材料缺口算出来的默认关。
说「现在跑」开的手动场两边都不吃，永远走默认关。

### 早晚场的两个自动让路

- **你正在玩**：08:00 / 22:00 触发时如果检测到模拟器已经开着，本场直接跳过，发一条灰色
  「⏭️ 已跳过」，**不会把你的游戏关掉**。手动说「现在跑」不受这条限制。
  抄作业、通关队列、04:30 的仓库对表也走同一条闸门，都会说明「模拟器正在使用，本次未执行」。
- **你设了跳过**：发「⏭️ 已跳过」，不开模拟器。**另一场和手动开跑都照样能跑。**

### 日常跑完之后

如果活动通关队列是开着的（`clearing_enabled`，**默认关闭**），日常收尾会顺手派发一轮队列，
结束时发一条「通关队列本轮结束」。派发不出去也会发红色提示，不会静默。

### 新活动上线时

活动轮换被检测到 → 自动取 MAA 的第一推荐关 → 去 prts.plus 重新搜作业 →
只有**完全满足练度、没有任何软硬缺口**的 Top-1 普通作业，才会发一张确认卡给你。

- 暂时没有满足条件的作业：发一条 ⏳ 提示，每 30 分钟自动重试，**不会自己开跑**。
- 活动结束（连续两次轮询都空）：发 🏁「活动已结束」，旧卡按钮收起。
- 活动中途切换：旧卡自动失效，不会拿旧作业去打新活动。

### 通关队列卡住时

队列在某一关反复打不过，或者 MAA 根本没为这关写导航定义，会发一张
🙋「需要你手动打一次」的卡片，队列停在那里等你。**在你点掉之前，日常照常刷理智**，
理智不会白白溢出。

## 二、能点的卡片

### 🌱 今日计划卡（早场 07:50 / 晚场 21:50）

**恰好两行控件**：

| 控件 | 作用 |
|---|---|
| 🎯 选择本场要刷的关卡 | 上次作战关卡 / `1-7` / 当天开放的资源本 / 当期活动关，**每个选项都写着这关掉什么**（`SR-8 · 异铁组`） |
| ⏭️ 跳过本场（早场 08:00） / ▶️ 恢复本场 | 只关掉**这一场**，另一场和手动开跑都不受影响 |

卡片上的字段：**刷什么**（并标明这关是自动定的还是你选的）、**为什么**（缺口理由或降级说明）、
**本场跳过**、**当前活动关**、**活动截止**（读不到就不显示这行）、理智规则、每日剿灭；
早场卡还多一个**上游更新**。

**本场刷哪个关默认不用你选**：发卡时会按仓库里的材料缺口（可用天数 = 库存 ÷ 日均消耗）
自动定好，卡片上写明理由，比如「异铁组 库存 66、日均 4.00，约只够 16.5 天」。
你在某一场手动选过之后，**当天那一场就不会再被自动改**（另一场照样自动算），次日重新算。

卡片会**明说自己有多可信**：还没攒够消耗数据时不自动改关，只沿用默认关并标「降级」；
上游掉落表和手工表都查不到关卡的材料直接不推荐并列出来——它不猜关。

### 🤖 抄作业卡（你说「抄作业」之后）

一个下拉。卡上先列出**现在能抄的关**：关卡 + 主掉落 + 上游有没有导航 + 活动截止；
下拉里只放**上游写了导航定义**的关（没写的 MAA 根本进不去），没有活动时退化成
当天开放的资源本 + `1-7`。选中一关就直接去 prts.plus 搜作业，接着走下面那张候选卡。

再说一次「抄作业」会发一张新卡，上一张的下拉同时被收起。

### 🤖 抄作业候选卡（你说「抄 XX」之后）

最多 3 个候选，每个两个按钮：

- **▶️ 1 / 2 / 3** — 按普通模式打这份作业
- **🔥 1 / 2 / 3** — 按突袭模式打
- **❌ 取消**
- **🔄 换一批** — 重新搜一次

卡上会写每份作业的练度满足度和缺口（形如「缺：史尔特尔 专精2（你专精1）」）。
没接森空岛时会降级成按热度排序，并明确标注「练度未校验」。

### 🆕 新活动确认卡（自动发的）

只有两个按钮：**✅ 确认执行（普通）** 和 **❌ 取消**。没有突袭、没有换一批——
这张卡只在作业完全满足练度时才出现，不需要你再挑。

点确认后会现场复核一遍活动和理智；活动已轮换、理智读不出来或不够，都会当场拒绝并说明原因。

### 🙋 需要你手动打一次（队列卡住时）

一个按钮：**✅ XX 已完成**。

意思是「我已经在游戏里手动打过这一关了」——**只有你本人能点**，
在聊天里让机器人替你点是不行的。点完队列从下一关继续。

## 三、能说的话

在频道里直接说，会被翻译成对应操作：

| 你说 | 会发生什么 |
|---|---|
| 「早上刷 CE-6」「晚上换 1-7」 | 改**那一场**刷的关 |
| 「刷上次的本」 | 沿用游戏里最近一次作战的关卡（也要说是哪一场） |
| 「早场别跑」「今晚跳过」 | 只关掉那一场 |
| 「恢复早场」 | 撤销上一条 |
| 「今天怎么跑」「看计划」 | 一次念完早晚两场 |
| 「现在跑」 | 立刻开一场手动日常（**设了跳过也照跑**，走默认关） |
| 「最近怎么了」「看日志」 | 最近一次执行的中文结果 |
| 「抄作业」「有什么关能抄」 | 发一张抄作业卡（现在能抄的关一览 + 下拉） |
| 「抄 TO-9」「TO-9 有没有作业」 | 去 prts.plus 搜作业，发候选卡 |
| 「作业结果呢」「匹配到哪了」 | 报当前那次搜索的状态 |
| 「不抄了」「换一批」 | 引导你点候选卡上的 ❌ / 🔄 |
| 「通关队列到哪了」 | 报队列进度 |
| 「开始自动通关这个活动」 | 启动队列（默认关闭时会明确拒绝并说明原因） |
| 「不打了」「停掉队列」 | 停队列 |
| 「现在推一轮队列」 | 立刻推一轮（黑名单时段会拒绝，见下） |

关卡说得不清楚时，它会先问一句，**不会猜**。

### 说了也不会答应的

- **碎石** — 永久关闭，没有开关，脚本层面硬拒。
- **改吃药规则** — 固定为：普通理智药 0、只自动用配置窗口内临期的药、源石 0。
- **改任务链 / 次数 / ADB / 模拟器 / Discord 配置 / 默认配置** — 一律拒绝。
  能改的只有**今天某一场刷哪一关**和**那一场是否跳过**。
  没说是早场还是晚场时它会先问一句，不会替你挑，也不会两场都改。
- **贴森空岛 token** — 绝不接收也绝不复述，会引导你去本机终端粘贴。

### 什么时候会被拒绝

- **正在跑**的时候再说「现在跑」→ 明确告诉你已经在跑什么，不重复启动。
- 抄作业 / 推队列撞上 **08:00 或 22:00 前 25 分钟** → 拒绝，让你等日常跑完。
- 推队列撞上 **04:20–05:00 的仓库对表窗口** → 拒绝，避免抢锁。
- 改计划时如果本场正在跑 → 不打断本场，会告诉你改的是哪一场、什么时候生效。
- 日常 / 抄作业 / 队列 / 仓库对表要开模拟器时**发现模拟器已经开着** → 本次不执行，
  发一条说明，不会把你踢出游戏。

## 四、消息速查

看到这些开头，大概知道是什么事：

| 消息开头（原文） | 含义 |
|---|---|
| `🌱 MAA 今日计划 · 早场 08:00` / `· 晚场 22:00` | 07:50 / 21:50 的两张计划卡 |
| `🤖 抄作业：现在能抄的关` | 你说「抄作业」之后的一览卡 |
| `🌱 MAA 日常·早/晚场开始` | 开跑了，步骤在它下面的子区里滚动 |
| `✅ / ❌ MAA 日常·完成/失败` | 战报 + 主界面截图 |
| `⏭️ 已跳过` | 你把**这一场**设了跳过，或者检测到你正在玩 |
| `⏭️ MAA 仓库对表已跳过` | 04:30 到期了，但模拟器在用，明天自动重试 |
| `🤖 XX 抄作业候选` | 你要的作业搜出来了 |
| `🆕 XX：确认执行` | 新活动自动匹配到作业，等你确认 |
| `▶️ 开始抄作业` / `✅ ❌ 抄作业` | 抄作业的开跑与结果 |
| `⛔ 抄作业未启动，可重试` | **还没进战、理智没消耗**，原确认卡还能再点 |
| `❌ 抄作业失败` | 可能已经消耗理智，**不会自动重跑**，也不建议你手动重试 |
| `⏳ / ❌ 自动作业尚未就绪` | 新活动暂时没有满足练度的作业，30 分钟后自动再试 |
| `🏁 活动已结束` | 活动从 MAA 视图消失，卡片收起 |
| `🙋 需要你手动打一次` | 队列卡住了，等你手动打过再点「已完成」 |
| `⏸️ 通关队列本轮未启动` | 队列这轮没跑，附原因 |
| `⛔ EX 段未入队` | 森空岛读不到进度，EX 被闸门挡住（不是打完了） |
| `❌ MAA 上游更新失败 / 活动关探测失败 / Depot 对表失败` | 旁路任务出错，日常本身不受影响 |

## 五、几条要知道的规矩

- **频道里永远看不到 maa-cli 的原始 stdout/stderr**，只有中文步骤和战报。CLI 原文只写本地日志。
- **一次只跑一件事**：日常、抄作业、通关队列、仓库对表共用同一把锁，不会互相抢模拟器。
- **计划变更不打断已开始的场次**：开跑时会把当场计划快照下来，跑到一半改计划只影响下一场。
- **今天的覆盖明天自动失效**，不用手动撤；而且是**按场次**记的，改一场不碰另一场。
- **下拉选项发给 Discord 的是不透明编号**，真实关卡名只存在本机的按钮登记表里——
  从 Discord 这一侧注入不了任意关卡。
- **跑完会把模拟器和游戏进程清干净**，并断开 ADB。
