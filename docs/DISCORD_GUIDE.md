# Discord 使用手册

这份文档只讲一件事：**在 Discord 那个频道里，会自动发生什么，以及你能做什么。**
不涉及部署和代码，那些看 [README.md](../README.md) 和 [DEV_GUIDE.md](./DEV_GUIDE.md)。

频道里说话**不用 @ 机器人**，直接说人话就行。

---

## 一、自动发生的事

### 每天固定发生（北京时间）

| 时间 | 做什么 | 频道里会看到 |
|---|---|---|
| 每 15 分钟 | 检查当期活动，把还没打过的关排进自动作业 | 平时安静；排出一轮时发「🤖 自动作业已排程」（见下） |
| 04:30 | 仓库对表（满 7 天才真跑，未到期不开模拟器） | 只在失败时发 ❌ |
| 07:50 | 跟随 maa-cli / MaaCore 更新 → 刷新活动关 → 发**早场计划卡** → 清掉 24h 前的子区和 14 天前的运行文件 | 🌱 **MAA 今日计划 · 早场 08:00**（可点） |
| 08:00 | 按**早场**的计划跑一遍完整日常 | 🌱 开始 → 子区里滚动步骤 → ✅/❌ 战报 + 主界面截图 |
| 21:50 | 刷新活动关 → 发**晚场计划卡**。**不跟随上游更新**（早上跟过了） | 🌱 **MAA 今日计划 · 晚场 22:00**（可点） |
| 22:00 | 按**晚场**的计划跑，任务链完全一样 | 同上 |

发新计划卡时，旧计划卡的按钮会被**清空**，避免同时存在两张能点的卡——
所以 21:50 之后早场那张就点不动了，这是故意的。

### 一天两张卡，两场分开管

早场卡管 08:00，晚场卡管 22:00。**你在一张卡上改的关卡或跳过，只影响那一场**：
早上选了 `CE-6`，晚上仍然走系统按材料缺口算出来的默认关。
说「现在跑」开的手动场两边都不吃，永远走默认关。

### 早晚场的两个自动让路

- **你正在玩**：08:00 / 22:00 触发时如果检测到模拟器已经开着，本场直接跳过，发一条灰色
  「⏭️ 已跳过」，**不会把你的游戏关掉**。手动说「现在跑」不受这条限制。
  抄作业、04:30 的仓库对表也走同一条闸门，都会说明「模拟器正在使用，本次未执行」。
- **你设了跳过**：发「⏭️ 已跳过」，不开模拟器。**另一场和手动开跑都照样能跑。**

### 一场日常里可能刷两个关

刷理智那步现在可能出现**两段**：第一段刷缺口第一名、**刷够就停**；第二段刷第二名，
把剩下的理智用完。战报里它们分别叫「刷理智」和「刷理智·续」。
没有缺口上限时（刚部署、仓库还没对够表、或者你手动选了关）就只有一段，打到理智不足为止。

### 日常开跑前的理智让路

开跑前会估一下理智。**不够刷默认关**（比如刚被自动作业花掉）就跳过「刷理智」，
开跑消息里会写明；剿灭 / 基建 / 公招 / 商店 / 领奖照常。估不出来（森空岛读不到）
就照常刷——宁可多刷一场。

### 新活动上线时（自动抄作业）

活动上线被检测到 → 发一条「🆕 XX 已上线」→ 把**上游写了导航定义的关**排成待办
（`SR-1`、`SR-2`、…，包括将来的 EX / S），按理智一轮一轮打，**普通打完接着打突袭**。

- 排出一轮时发一张「🤖 自动作业已排程」卡：这一轮打哪几关、要多少理智、预计几点开始。
  卡上**只有一个「❌ 取消本轮」按钮**——不需要你确认，到点自己跑。
- 理智不够就排到理智够的那一刻；到点若你正在玩、或日常快开始了，就顺延到下一轮。
- 跑完发一条**多关战报**，逐关列出 ✅ / ❌。一关失败不影响后面几关；
  导航这类环境问题才会整轮停下。
- 练度不满足 / prts 上暂时没作业的关：**跳过**，每 30 分钟自动再试，
  **绝不用助战、绝不忽略作业的练度要求**。等你练度够了它自己会补上，也可以手动抄。
- 已经打过的关不会再抄：本地记账 + 森空岛的 zone 全清两条判据都算。
- 活动结束（连续两次轮询都空）：发 🏁「活动已结束」，没打完的一轮收起。
- 活动中途切换：旧的一轮自动失效，不会拿旧作业去打新活动。

## 二、能点的卡片

### 🌱 今日计划卡（早场 07:50 / 晚场 21:50）

**恰好两行控件**：

| 控件 | 作用 |
|---|---|
| 🎯 选择本场要刷的关卡 | 上次作战关卡 / `1-7` / 当天开放的资源本 / 当期活动关，**每个选项都写着这关掉什么**（`SR-8 · 异铁组`） |
| ⏭️ 跳过本场（早场 08:00） / ▶️ 恢复本场 | 只关掉**这一场**，另一场和手动开跑都不受影响 |

卡片上的字段：**刷什么**（并标明这关是自动定的还是你选的）、**为什么**（缺口理由或降级说明）、
**本场跳过**、**当前活动关**、**活动截止**（读不到就不显示这行）、理智规则、每日剿灭；
早场卡还多一个**上游更新**。

**本场刷哪个关默认不用你选**：发卡时会自动算好，你在某一场手动选过之后，
**当天那一场就不会再被自动改**（另一场照样自动算），次日重新算。

#### 「为什么」这一栏怎么读

一行长这样：

```
1. 异铁组 → `SR-8` 综合 0.97（稀缺 0.93 / 缺口 1.00 / 效率 1.00）；还缺 52 个、27.02 理智/件、比常驻便宜 1.49 倍，预计复刻 2027-09-17
```

从左往右：**材料 → 去哪刷 → 总分**，然后是三项分（各 0~1，越大越该刷）：

| 分项 | 它在问什么 | 什么时候接近 1 |
|---|---|---|
| **稀缺** | 这次不刷，下次能这么便宜刷是什么时候 | 只有活动关明显比常驻关便宜（≥1.3 倍）时才有分；活动关一关，下次要等复刻（按历史中位数 378 天估），所以活动期几乎都接近 1。常驻随时能刷的材料是 **0** |
| **缺口** | 按 30 天用量算还差多少，折成理智值有多少 | 库存快见底、而且这材料本身值钱时接近 1。够用就是 0 |
| **效率** | 今天能刷的关里，这材料的「每理智产出」离全游戏最优差多少 | 今天正好能刷到全游戏最优的那一关时 = 1 |

后面那截是佐证：**还缺多少个**、**多少理智换一个**、**比常驻便宜几倍 / 预计什么时候复刻**。

总分是三项按权重（默认 稀缺 0.5 / 缺口 0.3 / 效率 0.2）加权平均，排第一的就是本场要刷的关。

同一栏里还会看到：

- `🎯 刷够 52 个就停，剩下的理智去 SR-7` — 第一关刷够缺口就换第二名的关，理智不浪费。
- `候选集：活动期：候选集只有活动关（D5）` — **活动期间只刷活动关**（理智要 all in 才换得完
  代币商店），所以下面常常跟一行「不在本场候选集里（活动期只刷活动关）：龙门币→CE-6…」，
  那是设计不是故障。想刷资源本就从下拉手动选，手动选的关也不带「刷够就停」的上限。
- `⚠️ 降级：…` — 数据不全时照样会定关，但会把原因写出来：外部掉率抓不到（用本地缓存
  或干脆缺两项分）、仓库还没攒够 2 次对表（缺口那项退回手工权重，而且**不设刷够上限**）。
- 最后一行永远是数据来源署名。

卡片会**明说自己有多可信**：上游掉落表和手工表都查不到关卡的材料直接不推荐并列出来——它不猜关。

### 🤖 抄作业卡（你说「抄作业」之后）

一个下拉，外加一张**进度一览**。一览里每关一行，标着它现在是什么状态：

| 标记 | 意思 |
|---|---|
| ✅ 已通 | 所需模式（活动关是普通 + 突袭）都打过了 |
| 🔁 普通已通、突袭待补 | 突袭那次没过，下一轮只补突袭 |
| ⏳ 排程 14:30 | 已经在这一轮的清单里，到点自己跑 |
| 🚫 练度不满足（缺：…） | prts 上没有你能打的作业，写清缺什么 |
| 🔒 …大概率未解锁 | 森空岛进度显示这关还没解锁，点了可能空跑 |
| ⛔ 上游无导航 | MAA 没为这关写选关路线，**进不去**，也不在下拉里 |
| 🕐 待抄 | 还没轮到 |

**下拉里选一关＝立刻开跑**：直接去 prts.plus 搜作业，搜到就排程 + 开跑，
搜不到就发一张红卡写清原因。**已通的关也能选**，那是重打。

「✅ 已通」只认两件事：抄作业自己打赢过、或森空岛显示整个章节全清。
**你自己手打通的关它不知道**，会当成没打过排进自动一轮——活动一上线先说一句
「SR-7 我自己打过了」，它就记进账本不再抄。
没有活动时下拉退化成当天开放的资源本 + `1-7`。

再说一次「抄作业」会发一张新卡，上一张的下拉同时被收起。

### 🤖 已排程卡（自动排出一轮时 / 你选完关之后）

**只有一个按钮：❌ 取消本轮。** 卡上写这一轮打哪几关、每关什么模式、要多少理智、
预计几点开始。不需要你确认——到点条件满足就自己跑。

一旦开跑，这个按钮就会被收起（那时候取消已经没有意义了）。

### 🎲 肉鸽卡（你说「刷肉鸽」之后）

**4 个下拉 + 1 行 3 个按钮**，正好占满一张卡的 5 行：

| 控件 | 选什么 | 默认 |
|---|---|---|
| 主题 | 傀影 / 水月 / 萨米 / 萨卡兹 / 界园 / 黑流树海 | 萨卡兹 |
| 模式 | 刷源石锭 / 刷等级 / 烧水凹开局（萨米多一个刷坍缩范式；黑流树海是它自己的三个策略） | 刷源石锭 |
| 难度 | 不指定 / MAX / n…0（上限按主题 15 或 18） | 手册推荐（萨卡兹 4、界园 3、水月 3、萨米 4、傀影 2、黑流树海不指定） |
| 分队 | 该主题能用的分队（主题专属 + 通用 6 个 + 高规格） | 萨卡兹刷锭用点刺成锭分队，其余指挥分队 |
| 按钮 | ▶️ 开始 / ⏹️ 本局结束后停止 / ⏏️ 立即中止（会丢当前局） | — |

- **选下拉不会开跑**，只是记下来；点了「▶️ 开始」才真的开模拟器。
- **换主题会自动重发一张新卡**（模式 / 难度 / 分队的选项都随主题变），上一张同时收起。
- **换主题前先在游戏里把那个肉鸽主题置顶到终端**——上游的自动导航不保证长期可用。
- 「⏹️ 本局结束后停止」= 这一局打完再退，**进度不丢**；
  「⏏️ 立即中止」= 当场停，**当前这一局作废**（分数和源石锭都不算）。
- 被「立即中止」过之后，**下一次必须还是同一个主题**——上游只在同主题下才会自己
  放弃残局。想换主题就先用原主题跑一局收尾，卡上会写着这件事。
- 肉鸽**不消耗理智**，不影响日常刷图；但它一样开模拟器、一样占那把锁。
- 每打完一局发一条进度，整轮结束发一条战报（局数、逐局结果、上游的逐局小结、停止原因）。

## 三、能说的话

在频道里直接说，会被翻译成对应操作：

| 你说 | 会发生什么 |
|---|---|
| 「早上刷 CE-6」「晚上换 1-7」 | 改**那一场**刷的关 |
| 「刷上次的本」 | 沿用游戏里最近一次作战的关卡（也要说是哪一场） |
| 「早场别跑」「今晚跳过」 | 只关掉那一场 |
| 「恢复早场」 | 撤销上一条 |
| 「今天怎么跑」「看计划」 | 一次念完早晚两场 |
| 「现在跑」 | 立刻开一场手动日常（**设了跳过也照跑**，走默认关） |
| 「最近怎么了」「看日志」 | 最近一次执行的中文结果 |
| 「抄作业」「有什么关能抄」 | 发一张抄作业卡（现在能抄的关一览 + 下拉） |
| 「抄 SR-8」「SR-8 有没有作业」 | 去 prts.plus 搜作业，**搜到就直接开跑** |
| 「活动打到第几关了」「哪些关还没打」 | 发抄作业卡，一览里每关都有状态 |
| 「这轮到哪了」 | 报当前这一轮的状态 |
| 「不抄了」「取消这轮」 | 引导你点「已排程」卡上的 ❌ |
| 「再打一遍 SR-6」 | 重打（已通的关也允许） |
| 「SR-7 我自己打过了」「别再抄 SR-7」 | 记进账本，自动抄作业从此跳过这关（它不知道你手动打过的关，得你说一句） |
| 「标错了」「SR-7 其实没打过」 | 撤销那条记账，下一轮重新考虑 |
| 「刷肉鸽」「打集成战略」「换个肉鸽主题」 | 发一张肉鸽配置卡，参数你自己在卡上点 |
| 「肉鸽停」「打完这局停」 | 本局结束后退出，进度不丢 |
| 「肉鸽立刻停」「马上停」 | 当场停，**当前这一局作废** |
| 「肉鸽到哪了」「跑了几局了」 | 报本轮参数和逐局结果 |

关卡说得不清楚时，它会先问一句，**不会猜**。

**肉鸽的主题 / 模式 / 难度 / 分队只能你在卡上点**——聊天里说「用萨米难度 8 开跑」，
它也只会给你发一张卡，不会替你选、也不会替你按「开始」。

### 说了也不会答应的

- **碎石** — 永久关闭，没有开关，脚本层面硬拒。
- **改吃药规则** — 固定为：普通理智药 0、只自动用配置窗口内临期的药、源石 0。
- **改任务链 / 次数 / ADB / 模拟器 / Discord 配置 / 默认配置** — 一律拒绝。
  能改的只有**今天某一场刷哪一关**和**那一场是否跳过**。
  没说是早场还是晚场时它会先问一句，不会替你挑，也不会两场都改。
- **贴森空岛 token** — 绝不接收也绝不复述，会引导你去本机终端粘贴。

### 什么时候会被拒绝

- **正在跑**的时候再说「现在跑」→ 明确告诉你已经在跑什么，不重复启动。
- 抄作业撞上 **08:00 或 22:00 前 25 分钟** → 拒绝，让你等日常跑完。
  自动的会自己顺延；**你手点的那一关不排队**，日常跑完重新选一次即可。
- 抄作业撞上 **04:20–05:00 的仓库对表窗口** → 自动的顺延、手动的拒绝，避免抢锁。
- 一轮里每开新的一关前会看**距下一场日常还剩多久**，不足 40 分钟就收尾，剩下的下一轮打。
  这条同样管「能不能开这一轮」，所以离日常太近时手点也会被拒。
- 上游没为某关写导航定义 → 它既不在下拉里也不会被自动打，一览里标 ⛔。
  这不是「关卡没解锁」，是 MAA 没写选关路线，**等下去不会自己变好**。
- 改计划时如果本场正在跑 → 不打断本场，会告诉你改的是哪一场、什么时候生效。
- 日常 / 抄作业 / 仓库对表 / 肉鸽要开模拟器时**发现模拟器已经开着** → 本次不执行，
  发一条说明，不会把你踢出游戏。
- 肉鸽上一轮被「立即中止」过，这次却选了**别的主题** → 拒绝，让你先用原主题跑一局收尾
  （上游只在同主题下才会自己放弃残局，换主题会卡死）。
- 肉鸽正在跑的时候改卡上的下拉 → 拒绝，参数要等这一轮停下来再改。

## 四、消息速查

看到这些开头，大概知道是什么事：

| 消息开头（原文） | 含义 |
|---|---|
| `🌱 MAA 今日计划 · 早场 08:00` / `· 晚场 22:00` | 07:50 / 21:50 的两张计划卡 |
| `🤖 抄作业：现在能抄的关` | 你说「抄作业」之后的一览卡 |
| `🌱 MAA 日常·早/晚场开始` | 开跑了，步骤在它下面的子区里滚动 |
| 战报里的 `⚔️ 刷理智·续` | 第一个关刷够缺口后接着刷的第二个关；没出现就是没设上限或理智先用完了 |
| `✅ / ❌ MAA 日常·完成/失败` | 战报 + 主界面截图 |
| `⏭️ 已跳过` | 你把**这一场**设了跳过，或者检测到你正在玩 |
| `⏭️ MAA 仓库对表已跳过` | 04:30 到期了，但模拟器在用，明天自动重试 |
| `🆕 XX 已上线` | 检测到新活动，开始自动排作业 |
| `🤖 自动作业已排程` / `🤖 已排程：SR-8` | 这一轮的清单（自动 / 你手动选的） |
| `▶️ 开始抄作业：共 N 项` | 这一轮开跑了 |
| `✅ / ⚠️ 抄作业本轮结束：N/M 通过` | 多关战报，逐关列结果；⚠️ 表示有关没过或中途停了 |
| `❌ XX 抄作业未开始` | 搜不到能打的作业 / 森空岛读不出来，**没碰模拟器** |
| `⏸️ 自动作业本轮未启动` | 锁被占或模拟器在用，这一轮顺延，附原因 |
| `🎲 肉鸽（集成战略）` | 你说「刷肉鸽」之后的配置卡（4 个下拉 + 3 个按钮） |
| `▶️ 开始刷肉鸽` | 这一轮开跑了，参数写在里面 |
| `🎲 肉鸽第 N 局结束` | 每打完一局一条：结算 / 放弃 / 被中断 / 报错，带经验与投资 |
| `✅ / ⚠️ 肉鸽本轮结束：共 N 局` | 汇总战报，含逐局结果、上游小结和停止原因；⚠️ 表示有局没干净结束 |
| `⏸️ 肉鸽本轮未启动` | 锁被占或模拟器在用，这一轮没开，附原因 |
| `🏁 活动已结束` | 活动从 MAA 视图消失，未打完的一轮收起 |
| `❌ MAA 上游更新失败 / 活动关探测失败 / Depot 对表失败` | 旁路任务出错，日常本身不受影响 |

## 五、几条要知道的规矩

- **频道里永远看不到 maa-cli 的原始 stdout/stderr**，只有中文步骤和战报。CLI 原文只写本地日志。
- **一次只跑一件事**：日常、抄作业、仓库对表、肉鸽共用同一把锁，不会互相抢模拟器。
- **计划变更不打断已开始的场次**：开跑时会把当场计划快照下来，跑到一半改计划只影响下一场。
- **今天的覆盖明天自动失效**，不用手动撤；而且是**按场次**记的，改一场不碰另一场。
- **下拉选项发给 Discord 的是不透明编号**，真实关卡名只存在本机的按钮登记表里——
  从 Discord 这一侧注入不了任意关卡。
- **跑完会把模拟器和游戏进程清干净**，并断开 ADB。
